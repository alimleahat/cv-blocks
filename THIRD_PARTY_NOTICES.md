## Timeline template

The Timeline template's layout (dates in a left column, coloured name and section bars) is inspired by the
"classic" style of [moderncv](https://github.com/moderncv/moderncv) (LaTeX Project Public License 1.3c).
No moderncv code is included; the look is recreated from scratch in CSS.
